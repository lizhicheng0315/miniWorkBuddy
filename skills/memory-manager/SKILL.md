# Memory Manager 技能

长期记忆让助手跨会话记住事实、偏好、习惯、重要事件和上下文。

## 执行步骤

1. 判断类型：事实（fact）/偏好（preference）/习惯（habit）/事件（event）/上下文（context）。
2. 写入：`memory_remember`，用第三人称、完整一句话描述；tags 补充领域标签。
3. 召回：用户问相关话题时，优先使用系统已注入的 `[长期记忆]`；追问时调用 `memory_recall`。
4. 去重：与已有记忆内容高度重复时，直接更新旧条目而不是新增一条。
5. 遗忘：用户明确说"忘掉/删除XX"时，用 `memory_forget` 按 ID 或关键词删除。

## 质量标准

- 不记忆一次性指令、临时闲聊、敏感的账号密码等凭据。
- 记忆内容要可独立理解：例如"用户每天早上 9 点先回邮件"而不是"他喜欢这样"。
- 重要程度 1-5：会影响长期决策的喜好打 3+；暂时信息打 1-2。
